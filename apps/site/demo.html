Live demo

Run a real payment, right here.

These buttons run the demo agent on our server: a real agent with its own key and spending policy, paying real sats on Tachi, with every settlement re-fetchable. Your browser only presses the button. Want the agent on your machine? Run the same SDK yourself: npm run demo:pay -- inference.

One click makes one real settlement (about 5–60 seconds while the transaction commits). Payments run one at a time.

The demo wallet is real and finite, so runs are rate limited (6 per hour per client). Each response includes the wallet balance and the exact sats402 verify command for its settlement.

How the agent works

The interesting part is step 2: the agent decides, on its own, whether it is allowed to pay.

1

Challenge. The service answers 402 with its price and payment terms.

2

Policy. Per-call cap, session budget, payee allowlist. A refusal happens here, locally, before any transaction exists.

3

Settlement. The agent signs and broadcasts its own tachi_tx for exactly the price asked. Its key, its money, its signature.

4

Proof and retry. The retry carries the settlement id. The service verifies it on-chain and serves the product.
