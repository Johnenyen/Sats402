Pay-per-request,

No accounts. No API keys. No custodian.

Sats402 is the SDK and protocol that enables autonomous AI agents to make pay-per-request micropayments using native sats on Tachi. An agent pays for each call by signing its own transaction; the service verifies by reading the chain. Settlement is committed on-chain in about 5.5s (Tachi consensus finality). The HTTP round-trip is what the agent sees.

Built for the agent economy, on Bitcoin

Sats402 is the x402 exact scheme on Tachi: the wire format the standard defines, settled as a Tachi transaction. The money moves exactly once, and the proof of payment is a transaction id anyone can check.

For agents

A spending policy is part of the SDK

Per-call cap, session budget, payee allowlist. A call that breaks policy is refused locally, before any transaction exists.

For services

One middleware, zero custody

Drop the paywall in front of any handler. It issues the challenge and verifies payment by reading the chain. It never holds a key.

For everyone

Receipts you can re-fetch

Every settlement is a tx id on Tachi. Check it on the verify page or with one command in the CLI (from a checkout until the npm package is published).
