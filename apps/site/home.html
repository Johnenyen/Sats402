Sats402 is the SDK and protocol that enables autonomous AI agents to make high-frequency, low-value payments using native sats on Tachi. An agent pays for each call by signing its own transaction. The service verifies by reading the chain. No accounts, no API keys, no custodian.

Three requests, no dashboard

The same flow every paid API in this ecosystem uses. Nothing to sign up for, nothing to configure.

1

Call the endpoint. The service answers 402 with its price in sats and a payment challenge.

2

Sign a payment. The agent checks its own spending policy, then signs and broadcasts its own tachi_tx for exactly the price asked.

3

Retry and get paid data. The retried request carries the payment proof. The service verifies it against the chain and responds 200.

Built for the agent economy, on Bitcoin

Sats402 is the x402 exact scheme on Tachi: the wire format the standard defines, settled as a Tachi transaction. The money moves exactly once, and the proof of payment is a transaction id anyone can check.

For agents

A spending policy is part of the SDK

Per-call cap, session budget, payee allowlist. A call that breaks policy is refused locally, before any transaction exists.

For services

One middleware, zero custody

Drop the paywall in front of any handler. It issues the challenge and verifies payment by reading the chain. It never holds a key.

For everyone

Receipts you can re-fetch

Every settlement is a tx id on Tachi. Check it on the verify page or with one command in the CLI (from a checkout until the npm package is published).
