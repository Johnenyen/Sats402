Sats402
pay-per-request, in native sats.

Sats402 is the SDK and protocol that enables autonomous AI agents to make high-frequency, low-value payments using native sats on Tachi. An agent pays per request by signing and broadcasting its own transaction. The service verifies the payment by reading the Tachi daemon. No custodian sits in the path.

Requirement 2

Support for the x402 / pay-per-request pattern

The three x402 v2 headers (PAYMENT-REQUIRED, PAYMENT-SIGNATURE, PAYMENT-RESPONSE) and a network binding for the exact scheme, written from the standard's scheme template. Unpaid call returns 402; the paid retry returns 200.

Requirement 3

Native sats settlement on Tachi

The agent signs and broadcasts its own tachi_tx. Settlement verification is read-only observation of daemon state. The signature binds the full challenge, so a payment cannot be moved onto another request.

How a payment works

      
Four steps. The money moves exactly once.

      

        
1
The agent requests a resource. The service answers 402 with a price in sats and a payment challenge (PAYMENT-REQUIRED).

        
2
The agent checks the price against its own spending policy: per-call cap, session budget, payee allowlist. A refusal here makes no transaction.

        
3
The agent settles: it signs and broadcasts its own tachi_tx for the exact amount to the payee's owner key.

        
4
The agent retries with the payment proof (PAYMENT-SIGNATURE). The service verifies by reading the daemon and responds 200 (PAYMENT-RESPONSE). A settlement is never charged twice.
