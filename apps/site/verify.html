Verification

Check anything yourself.

This page only reads the Tachi daemon: no keys, no wallet, no signing. A settlement record is daemon-returned and re-fetchable, which is exactly what makes it a receipt.

Verify a full payment payload

For developers: paste the PaymentPayload a client sent and every check runs live — the signature over the full challenge, the settlement re-fetch, and the committed record with payee amount and payer-owned inputs. 


  


  

    
From the command line

    

      One command. The same read-only check this page runs.
    

    
npx sats402 verify <txid>

settlement   37dd13293cf5fc6d…c86fe3a
state        committed   (daemon-returned)
epoch        967206
outputs
  6267b312b2ff30bf…a7702338f  5 sats
  e7ab2537b5d49e97…a0b4f9c319  588 sats
spent inputs
  e7ab2537b5d49e97…a0b4f9c319
note: Record is daemon-returned and re-fetchable: anyone can repeat this lookup.

    

      Until the sats402 package is published to npm, run it from a
      checkout: npm run verify -- <txid>.
